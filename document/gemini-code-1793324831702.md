# [FE-PRD] 프론트엔드 상세 기능 및 인터랙션 사양서

## 1. 아키텍처 및 라이브러리 스펙
- **Base Grid**: Bootstrap 5 Responsive Grid System (`col-12`, `col-md-6`, `col-lg-4`)
- **Slider/Carousel**: Swiper.js (`autoplay`, `loop`, `pagination`, `breakpoints`)
- **Form Controls**: Nice-Select (jQuery 기반 커스텀 셀렉트박스를 최신 모던 컴포넌트(Select/Dropdown)로 전환)
- **Schedule**: Datepicker UI / Timeline Line Animation
- **Typography**: Pretendard Dynamic Subset (400, 500, 600, 700)
- **Icons**: FontAwesome 6 WebFont/SVG
