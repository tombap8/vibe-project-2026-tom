# Discovery Expedition 온라인몰 PRD

## 1. 제품 개요

- **제품**: Discovery Expedition 공식 온라인몰을 참고한 반응형 웹사이트
- **목표**: 사용자가 브랜드 캠페인과 상품을 둘러보고, 카테고리·검색·쇼핑 관련 주요 기능에 접근할 수 있는 온라인 쇼핑 경험을 제공한다.
- **대상 사용자**: 모바일 및 데스크톱에서 Discovery Expedition 상품과 콘텐츠를 탐색하는 방문자
- **참고 서비스**: [Discovery Expedition 공식 온라인몰](https://www.discovery-expedition.com/)
- **제품 범위**: 홈 화면의 브랜드 콘텐츠와 상품 탐색 경험, 공통 탐색 UI 및 푸터

## 2. 사용자 경험 원칙

1. 모바일과 데스크톱에서 핵심 콘텐츠와 탐색 기능을 사용할 수 있어야 한다.
2. 사용자가 카테고리, 검색, 장바구니, 마이페이지, 메뉴 등 주요 쇼핑 기능에 쉽게 접근할 수 있어야 한다.
3. 이미지와 상품 정보 중심으로 브랜드 캠페인과 상품을 탐색할 수 있어야 한다.
4. 자동 재생이나 동작 효과는 사용자가 제어할 수 있어야 하며, 모션 감소 설정을 존중해야 한다.

## 3. 제품 범위 및 기능 요구사항

### 3.1 공통 헤더 및 탐색

- 브랜드 로고와 여성·남성·신발·용품·키즈 카테고리 탐색을 제공한다.
- 검색, 장바구니, 마이페이지, 전체 메뉴 진입 UI를 제공한다.
- 데스크톱에서는 메가 메뉴를 제공한다.
- 모바일에서는 카테고리 탐색과 하단 탭바를 통해 주요 기능에 접근할 수 있어야 한다.
- 아이콘만으로 표시되는 기능에는 목적을 알 수 있는 접근 가능한 이름을 제공한다.

### 3.2 히어로 캠페인

- 이미지와 텍스트를 결합한 세로 방향 캠페인 슬라이드를 제공한다.
- 캠페인에는 영문 타이틀과 한글 서브카피를 표시한다.
- 현재 슬라이드를 확인하고 이동할 수 있는 세로 페이지네이션을 제공한다.
- 자동 재생을 사용할 경우 일시정지 기능을 제공하며, 사용자의 모션 감소 설정이 활성화되면 자동 재생을 멈춘다.

### 3.3 디스커버리 숏츠

- 숏폼 콘텐츠를 탐색할 수 있는 이미지 카드 캐러셀을 제공한다.
- 원본의 Shoplive 영상 위젯은 본 프로젝트 범위에서 이미지 카드 캐러셀로 대체한다.

### 3.4 BEST ITEM

- `가장 사랑받는 베스트 아이템` 섹션을 제공한다.
- 상품 캐러셀에 상품 이미지, 상품명, 가격, 랭킹 정보를 표시한다.
- 상품 탐색을 위한 전체보기 동선을 제공한다.
- 상품 카드의 주요 정보와 기능은 터치 환경에서도 확인할 수 있어야 한다.

### 3.5 COLLECTION

- `THE ACTIVE LAYER` 컬렉션 섹션을 제공한다.
- 컬렉션 배너와 상품 목록을 함께 표시한다.
- 컬렉션 상품 및 전체 목록으로 이동할 수 있는 동선을 제공한다.

### 3.6 TREND PICK

- `디스커버러의 취향` 섹션에서 숏패딩, 경량패딩, 경량자켓, 후드티 카테고리를 제공한다.
- 카테고리 선택 시 해당 스타일픽 콘텐츠를 탐색할 수 있어야 한다.
- 선택 상태를 시각적으로 구분하고 접근성 상태도 함께 갱신한다.
- 좁은 화면에서는 카테고리 탭을 가로로 탐색할 수 있어야 한다.

### 3.7 푸터

- 주요 링크, SNS 링크, 사업자 정보, 언어 선택, 인증 정보 및 저작권 정보를 제공한다.
- 사업자 정보는 펼치고 접을 수 있는 UI로 제공한다.

### 3.8 모바일 고정 UI 및 보조 기능

- 모바일 하단 탭바에서 카테고리, 검색, 홈, 장바구니, 마이페이지에 접근할 수 있어야 한다.
- 채팅 상담 진입 버튼을 제공한다.
- 최근 본 상품을 확인할 수 있는 버튼과 팝업을 제공한다.
- 고정 UI가 화면 콘텐츠나 기기 안전 영역과 겹치지 않아야 한다.

## 4. 반응형 요구사항

- 모바일(최대 768px), 중간 화면(769–1279px), 와이드 화면(1280px 이상)에 대응한다.
- 콘텐츠는 화면 너비에 맞게 재배치되어야 하며, 페이지 전체에 의도하지 않은 가로 스크롤이 생기지 않아야 한다.
- 캐러셀과 가로 탭처럼 의도된 가로 탐색 UI는 사용할 수 있어야 한다.
- 검수 기준 뷰포트: 360px, 390px, 768px, 1024px, 1440px.

## 5. 비기능 요구사항

### 5.1 접근성

- 키보드만으로 모든 기능을 사용할 수 있어야 하며, 포커스 순서는 화면의 시각적 흐름과 일치해야 한다.
- 동적 상태와 선택 상태를 스크린리더에 전달해야 한다.
- 링크와 아이콘 버튼은 목적을 명확히 식별할 수 있어야 한다.
- 모달을 사용하는 경우 키보드 포커스 관리, Escape 닫기 및 닫은 뒤 포커스 복귀를 지원한다.
- 확대 및 보조기술 사용을 제한하는 뷰포트 설정을 사용하지 않는다.

### 5.2 성능

- 목표 Lighthouse 모바일 점수는 90 이상이다.
- 핵심 성능 목표:
  - LCP ≤ 2.5초
  - INP ≤ 200ms
  - CLS ≤ 0.1
- 이미지와 스크립트 크기를 관리하고, 첫 화면 밖의 이미지는 지연 로딩한다.

### 5.3 검색 노출 및 콘텐츠

- 페이지별로 고유한 제목과 설명을 제공한다.
- 페이지의 핵심 주제를 나타내는 제목과 목적이 명확한 링크 텍스트를 사용한다.
- 문구는 사용자가 이해하기 쉬운 한국어로 작성하고, 날짜와 문체를 일관되게 유지한다.
- 빈 상태에는 다음에 할 수 있는 행동을 안내하고, 오류에는 가능한 원인과 해결 방법을 알린다.

### 5.4 브라우저 지원

- 최신 두 개 메이저 버전의 Chrome, Edge, Safari(iOS 포함), Firefox, Samsung Internet을 지원한다.
- Internet Explorer는 지원하지 않는다.
- JavaScript가 비활성화되어도 핵심 콘텐츠와 링크를 확인할 수 있어야 한다.

## 6. 완료 기준

- 헤더, 캠페인 히어로, 숏츠, BEST ITEM, COLLECTION, TREND PICK, 푸터가 제품 범위에 맞게 제공된다.
- 사용자가 주요 탐색 기능과 모바일 고정 UI를 사용할 수 있다.
- 지정 뷰포트에서 레이아웃이 깨지지 않고, 의도하지 않은 가로 스크롤이 발생하지 않는다.
- 키보드 및 스크린리더 사용자가 핵심 기능과 상태를 확인하고 조작할 수 있다.
- 자동 재생 및 모션 효과가 사용자의 제어와 모션 감소 설정을 따른다.
- 성능 목표와 지원 브라우저에서의 동작을 검수한다.
